# 5laba_3sem — Консольный маркетплейс на C++

Лабораторная №5, 3 семестр. Консольное приложение «маркетплейс»: продавцы, покупатели, товары.

## Что внутри
- `marketplace.h` — логика (`addProduct`, регистрация/вход)
- `main.cpp` — меню продавца/покупателя
- `httplib.h` — заголовочная библиотека (задел под HTTP)

## Стек
C++

## Запуск
```bash
g++ main.cpp -o marketplace && ./marketplace
# 1 — регистрация продавца, 2 — покупателя, далее по меню
```

## Что изучено
Проектирование ролей, хранение товаров, консольный UX.
