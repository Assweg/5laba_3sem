# Консольный маркетплейс

![Стек](https://img.shields.io/badge/C%2B%2B17-334155?style=flat-square) ![Семестр](https://img.shields.io/badge/семестр-3-0f766e?style=flat-square) ![Статус](https://img.shields.io/badge/статус-%D0%A3%D1%87%D0%B5%D0%B1%D0%BD%D1%8B%D0%B9%20%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82-64748b?style=flat-square)

Лабораторная №5: консольное приложение с ролями продавца и покупателя, регистрацией и операциями с товарами.

## Состав

- [main.cpp](main.cpp) — меню и обработка действий пользователя.
- [marketplace.h](marketplace.h) — модели и операции маркетплейса.
- [httplib.h](httplib.h) — включённая в материалы сторонняя библиотека; основная точка входа остаётся консольной.

## Сборка и запуск

```bash
c++ -std=c++17 main.cpp -o marketplace_app
./marketplace_app
```

## Как пользоваться

После запуска выберите регистрацию или вход для нужной роли, затем следуйте пунктам меню. Другие локальные варианты этой лабораторной сохранены в [общем архиве](https://github.com/Assweg/nstu).
